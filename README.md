# 期权知识库与策略研究

从 0 构建的**期权知识库 + 策略研究工作区**。主要研究**加密货币期权**（BTC/ETH，以 Deribit 为主），以**通用理论为骨架**、加密市场为主要落地场景，传统市场（美股/A股）作为对照。

- 协作约定与内容规范见 [CLAUDE.md](./CLAUDE.md)
- AI 助手的角色与工作流见 [AGENT.md](./AGENT.md)
