# 术语表（中英文对照）

> 新术语在 docs/ 笔记中首次出现时，回写到此表。按主题分组，组内按字母/拼音。

## 基础
| 中文 | English | 简释 |
|------|---------|------|
| 看涨期权 | Call Option | 到期前/到期日以行权价买入标的的权利 |
| 看跌期权 | Put Option | 到期前/到期日以行权价卖出标的的权利 |
| 行权价 | Strike Price | 期权约定的买入/卖出价格 |
| 到期日 | Expiration | 期权失效的日期（加密通常 UTC 08:00） |
| 权利金 | Premium | 买方为获得权利支付的价格 |
| 内在价值 | Intrinsic Value | 立即行权能获得的价值 |
| 时间价值 | Time Value | 权利金中超出内在价值的部分 |
| 实值/平值/虚值 | ITM / ATM / OTM | In/At/Out of the Money |

## 希腊字母
| 中文 | English | 简释 |
|------|---------|------|
| Delta | Delta | 标的价格变动 1 单位时期权价格的变动 |
| Gamma | Gamma | 标的价格变动时 Delta 的变动 |
| Theta | Theta | 时间流逝对期权价格的影响（时间衰减） |
| Vega | Vega | 隐含波动率变动 1% 时期权价格的变动 |
| Rho | Rho | 利率变动对期权价格的影响 |

## 定价与波动率
| 中文 | English | 简释 |
|------|---------|------|
| 平价公式 | Put-Call Parity (PCP) | 同行权价同到期的看涨/看跌价格关系 |
| 二叉树 | Binomial Tree | 离散时间的期权定价模型 |
| BSM 模型 | Black-Scholes-Merton | 连续时间欧式期权定价模型 |
| 历史波动率 | Historical Volatility (HV) | 由历史价格计算的已实现波动率 |
| 隐含波动率 | Implied Volatility (IV) | 由期权价格反推的市场预期波动率 |
| 波动率微笑/曲面 | Volatility Smile / Surface | IV 随行权价/到期的分布形态 |
| VIX | VIX | 标普 500 隐含波动率指数 |
| DVOL | DVOL | Deribit 的 BTC/ETH 隐含波动率指数 |

## 加密期权专题
| 中文 | English | 简释 |
|------|---------|------|
| 反向/币本位合约 | Inverse / Coin-margined | 以标的币（BTC/ETH）计价与结算，引入额外非线性 |
| U 本位 | USDT/USDC-margined | 以稳定币计价与结算 |
| 永续合约 | Perpetual Swap | 无到期的合约，靠资金费率锚定现货 |
| 资金费率 | Funding Rate | 永续多空之间周期性支付，影响对冲成本 |
| 现金交割 | Cash Settlement | 到期以现金/币结算差价，不交割实物 |
| 链上期权 | On-chain Options | DeFi 协议(Lyra/Aevo 等)上的期权，AMM 定价 |
| 指数价格/预言机 | Index Price / Oracle | 多交易所综合的结算参考价 |
| 清算 | Liquidation | 保证金不足时的强制平仓 |

## 策略
| 中文 | English | 简释 |
|------|---------|------|
| 备兑开仓 | Covered Call | 持标的 + 卖 Call，收租封顶上行 |
| 保护性看跌 | Protective Put | 持标的 + 买 Put，下行买保险 |
| 垂直价差 | Vertical Spread | 同到期、买卖不同行权价 |
| 跨式 | Straddle | 同行权价买/卖 Call+Put，赌波动 |
| 宽跨式 | Strangle | 不同行权价的 Call+Put |
| 蝶式 | Butterfly | 买1卖2买1，限险赌钉价 |
| 铁鹰 | Iron Condor | 卖两个 OTM 价差，限险收租 |
| 日历价差 | Calendar Spread | 卖近月买远月，交易期限结构 |
| 对角价差 | Diagonal Spread | 跨行权价+跨到期 |
| 比率价差 | Ratio Spread | 不等数量两腿，带裸腿风险 |
| 风险逆转 | Risk Reversal | 买一侧虚值卖另一侧，押偏斜 |
| 领口 | Collar | 保护性看跌 + 备兑，低成本锁区间 |

## 波动率与量化
| 中文 | English | 简释 |
|------|---------|------|
| 已实现波动率 | Realized Volatility (RV) | 由历史价格算出的真实波动 |
| 方差风险溢价 | Variance Risk Premium (VRP) | IV 系统性高于随后 RV 的溢价 |
| 方差互换 | Variance Swap | 直接结算已实现方差的合约 |
| 远期波动率 | Forward Volatility | 期限结构隐含的未来某段波动 |
| 波动率微笑/偏斜 | Smile / Skew | IV 随行权价的形状 |
| 期限结构 | Term Structure | IV 随到期的形状（contango/倒挂）|
| 波动率曲面 | Volatility Surface | IV=f(K,τ) |
| 风险中性 | Risk-neutral | 用复制对冲后的定价测度 |
| 凯利公式 | Kelly Criterion | 最大化长期复利的下注比例 |
| 压力测试 | Stress Testing | 极端情景下重定价的损益 |
