# 跳跃扩散：Merton 与 Bates

> 扩散模型（BSM、Heston、SABR）的价格路径都是**连续**的——配不出"一夜暴跌 20%"这种**跳空**，也就配不出加密**短到期还很陡的偏斜**和**厚尾**。**Merton 跳跃扩散**在扩散上叠加泊松跳跃；**Bates** = Heston + 跳跃，是贴合加密的"全家桶"。本篇给 Merton 的闭式（泊松加权 BSM）与直觉。

## 1. 符号表（Notation）

| 符号 | 含义 |
|---|---|
| $\lambda$ | 跳跃强度（年均跳跃次数） |
| $\mu_J,\ \delta$ | 单次跳跃的对数均值 / 对数波动 |
| $k = e^{\mu_J + \delta^2/2}-1$ | 单次跳跃的期望幅度 $E[J]-1$ |
| $\sigma$ | 扩散部分波动率 |

---

## 2. Merton 跳跃扩散：SDE `公认结论`

$$ \frac{dS}{S} = (r - q - \lambda k)\,dt + \sigma\,dW + (J-1)\,dN $$

- $dN$ 是强度 $\lambda$ 的**泊松过程**（跳不跳）； $J$ 是跳跃幅度，对数正态 $\ln J \sim \mathcal{N}(\mu_J,\ \delta^2)$ 。
- 漂移里的 $-\lambda k$ 是**补偿项**：保证含跳的标的在风险中性下期望回报仍是 $r-q$ 。

---

## 3. 闭式：泊松加权的 BSM 和 `公认结论`

由"以 $n$ 次跳跃为条件、求和所有可能跳跃数"得：

$$ \boxed{\ C = \sum_{n=0}^{\infty}\frac{e^{-\lambda\tau}(\lambda\tau)^n}{n!}\ C_{\text{BSM}}\big(S,K,\tau;\ \sigma_n,\ r_n\big)\ } $$

其中第 $n$ 项用调整后的波动率与利率：

$$ \sigma_n^2 = \sigma^2 + \frac{n\,\delta^2}{\tau},\qquad r_n = r - \lambda k + \frac{n\ln(1+k)}{\tau} $$

**直觉**：到期前可能跳 0 次、1 次、2 次……每种情形下"等效"成一个波动率/利率被调整过的 BSM，按泊松概率加权平均。

- $n=0$ 项（不跳）权重 $e^{-\lambda\tau}$ ，就是普通 BSM；跳得越多、 $\sigma_n$ 越大。
- **λ=0 时只剩 n=0，精确退化为 BSM**（已数值验证）。

## 4. 算例：跳跃如何加厚尾（已数值复算）

沿用 [BSM 标杆](../03-定价模型/03-BSM模型.md) `S=K=60,000, τ=0.25, σ=80%, r=10%, q=0`，加跳跃 $\lambda=2$ /年、 $\mu_J=-0.10$ （均值 −10% 的下跳）、 $\delta=0.15$ ：

| 模型 | ATM Call 价 |
|---|---|
| 纯 BSM | \$10,152.55 |
| Merton（含上述跳跃） | **\$10,551.61**（+\$399） |

- 跳跃让分布**厚尾** → 期权（尤其两翼）更值钱，ATM 也抬升 \$399。
- **负跳（ $\mu_J<0$ ）→ 左尾更厚 → put skew**：方向性跳跃直接生成偏斜，且**不随到期变平**（与 SV 不同，见 §5）。
- 用 [`tools/option_strategy.py`](../../tools/option_strategy.py) 的泊松加权 BSM 复算（λ=0 一致回到 \$10,152.55）。

## 5. 为什么加密非要跳跃模型不可 `公认结论`/`推导`

- **纯随机波动率的短到期偏斜会过快衰减**：SV 靠"vol 慢慢漂"产生偏斜，时间太短漂不动 → 短到期近乎对称。
- **但加密短到期偏斜很陡**（清算级联让"明天跳 15%"是真实概率）→ 只有**跳跃**能在短到期生成陡偏斜与厚尾。
- 所以贴合加密的是 **Bates = Heston + 跳跃**：用 SV 管波动率聚集/期限结构，用跳跃管厚尾/短端偏斜（见 §6）。

## 6. Bates 与模型谱系

| 模型 | = | 配什么 |
|---|---|---|
| BSM | 常数 σ | 一个点 |
| 局部波动率 | σ(S,t) | 静态整面（[11/01](./01-局部波动率与Dupire方程.md)） |
| Heston/SABR | 随机 vol | 微笑 + 期限（[11/02](./02-随机波动率Heston与SABR.md)） |
| Merton | 扩散 + 跳跃 | 厚尾 + 短端偏斜（本篇） |
| **Bates** | **Heston + 跳跃** | **全都要**（加密首选） |

> 代价：参数越多越难校准、越易过拟合。实务按需选最简够用的模型。

---

## 7. 加密视角

- **跳跃 = 清算级联 / 脱锚 / 黑天鹅**（[09/04](../09-加密期权专题/04-DVOL与加密波动率特征.md)、[09/07 特有风险](../09-加密期权专题/07-加密特有风险.md)）——加密的跳跃强度 λ 与跳幅都比股票大。
- 跳跃方向随 regime：暴跌期负跳（put skew），逼空期也可能正跳。
- **空头 Gamma / 卖波动率**最怕跳跃：一次跳吞掉很久的 [VRP carry](../08-进阶与量化/02-已实现与隐含波动率价差.md)（呼应 08/02 的"−22% 跳跃"算例）。

---

## 8. 常见误区

- ❌ 用纯扩散模型给加密短到期定价 → 配不出陡偏斜/厚尾，系统性低估两翼。
- ❌ 以为 Merton 没有闭式 → 它是泊松加权的 BSM 和，可半解析算。
- ❌ 忘了漂移补偿 $-\lambda k$ → 风险中性下期望回报会被跳跃带偏。
- ❌ 一上来就 Bates 全参数 → 参数多易过拟合，按需选模型。
