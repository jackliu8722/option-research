# 平价公式（Put-Call Parity）：无套利的基石

> 平价公式是期权里**最硬的一条关系**——它不依赖任何定价模型，只靠"无套利"。同行权价、同到期的 Call 和 Put，价格被锁死成一个等式。理解它，你就有了一把**检查报价是否合理、拼合成头寸、反推隐含 r** 的万能尺。核心结论： $C - P = S e^{-q\tau} - K e^{-r\tau} = (F-K)e^{-r\tau}$ 。

## 1. 符号表（Notation）

| 符号 | 含义 | 单位/口径 |
|---|---|---|
| $C,\ P$ | 同 $K$ 同到期的 Call/Put 价 | USD |
| $S$ | 标的现价 | USD/BTC |
| $K$ | 行权价 | USD |
| $\tau$ | 剩余期限 | 年 |
| $r,\ q$ | 美元利率 / 持有收益（币侧） | 小数 |
| $F = S e^{(r-q)\tau}$ | 同到期远期/期货价 | USD |

> 加密默认 Deribit BTC/ETH（欧式、现金交割）；`r` 取基差/资金费率（[09/03](../09-加密期权专题/03-无风险利率r的选取.md)）。

## 2. 直觉：两个一样的未来，今天必须一样贵

无套利原理：**如果两个组合到期收益完全相同，今天的价格也必须相同**，否则就能"买便宜的、卖贵的"无风险套利。

构造两个组合（同 `K`、同到期 `T`，欧式）：

- **组合 A（保护性看跌）**：1 份标的 + 1 张 Put。
- **组合 B（受托看涨）**：1 张 Call + 现金 $K e^{-r\tau}$ （到期正好变成 $K$ ）。

到期收益：

| 情形 | 组合 A（标的+Put） | 组合 B（Call+现金 K） |
|---|---|---|
| $S_T > K$ | 持标的 = $S_T$ | 行权得标的 = $S_T$ |
| $S_T < K$ | 行 Put 卖出 = $K$ | 不行权，持现金 = $K$ |

两组合到期都等于 $\max(S_T, K)$ → **今天必须等价**。

---

## 3. 公式与推导

**结论（先给出）**：

$$ \boxed{\ C - P = S e^{-q\tau} - K e^{-r\tau} = (F - K)e^{-r\tau}\ } $$

**推导** `公认结论`：

1. 由 §2 两组合到期都 $=\max(S_T,K)$ ，无套利 ⇒ 今天等价：

$$ C + K e^{-r\tau} = S e^{-q\tau} + P $$

2. 移项即得 $C - P = S e^{-q\tau} - K e^{-r\tau}$ 。（无 $q$ 时 $S e^{-q\tau}=S$ 。）

3. 代入远期 $F = S e^{(r-q)\tau}$ ，把 $S e^{-q\tau}=F e^{-r\tau}$ 提出 $e^{-r\tau}$ ，得 $C - P = (F-K)e^{-r\tau}$ 。

**各项含义**： $K e^{-r\tau}$ = 行权价现值； $S e^{-q\tau}$ = 持有标的的现值（扣币侧收益）；远期式把 `r,q` 打包进 `F`。

> **远期形式（加密最好用）**：用交易所**期货价 `F`** 代入，就不必单独估 `r`、`q`——市场已经把它们打包进 `F` 了（见 [09/03 §4](../09-加密期权专题/03-无风险利率r的选取.md)）。

## 4. 特例与边界检验

- **ATM 远期**（ $F=K$ ）： $C-P=0$ ，Call 与 Put 等价。✓
- **`r>q`**（常态）： $F>K$ （对 ATM 现价）， $C>P$ 。✓
- **平价严格只对欧式成立**。Deribit BTC/ETH 是欧式 → 直接适用（[09/01](../09-加密期权专题/01-币本位与反向合约.md)）。
- **美式**只有**不等式边界**（因可提前行权），不是等式。
- 实务中买卖价差、手续费、资金费率、借券成本会让等式变成一个**区间**，不是一条精确线。

## 5. 敏感度 / 比较静态

| 输入 ↑ | $C-P$ 变化 | 直觉 |
|---|---|---|
| $S$ | ↑ | 多标的项 $S e^{-q\tau}$ |
| $r$ | ↑ | $K e^{-r\tau}$ 现值变小 |
| $q$ | ↓ | 币侧收益压低远期 |
| $K$ | ↓ | 行权价现值更大 |

> 注意：平价只约束 $C-P$ （差），不单独决定 $C$ 或 $P$ ——后者要靠 [BSM](./03-BSM模型.md) 等模型（需要 $\sigma$ ）。

---

## 6. 三大用途

### 用途 1：报价合理性检查 / 套利探测
若盘口的 $C - P$ 明显偏离 $(F-K)e^{-r\tau}$ ，要么有套利机会，要么——**更常见——是你的 `r`/`F` 取错了**（[09/03](../09-加密期权专题/03-无风险利率r的选取.md)）。

### 用途 2：合成头寸（接 [09/02](../09-加密期权专题/02-永续合约与资金费率对冲.md)）
移项即得"用两条腿合成第三条"：
- 合成多标的： $+C - P + K e^{-r\tau}$ （≈ 多 Call + 空 Put）。
- 合成多 Call： $+S + P$ （标的+Put，即保护性看跌）。
- 合成多 Put： $+C - S$ （Call + 空标的/空永续）。

### 用途 3：反推隐含 r
已知 `C, P, S, K` 求 `r`，正是 [09/03](../09-加密期权专题/03-无风险利率r的选取.md) 说的"从市场反推 carry"的另一条路径。

## 7. 算例（与 BSM 篇自洽）

`S = 60,000`，`K = 60,000`（ATM），隐含 `r = 10%/年`，`τ = 0.25`，无 `q`。

$$ K e^{-r\tau} = 60{,}000\,e^{-0.025} = 60{,}000 \times 0.97531 \approx 58{,}519 $$

$$ C - P = 60{,}000 - 58{,}519 = 1{,}481 $$

- 即**同 K 同到期的 ATM Call 应比 Put 贵约 \$1,481**（因为 `r>0`，远期在现价之上）。
- 远期式校验： $F = 60{,}000\,e^{0.025} \approx 61{,}519$ ， $(F-K)e^{-r\tau} = 1{,}519\times 0.97531 \approx 1{,}481$ ✓ 一致。
- **与 [BSM 篇](./03-BSM模型.md) 交叉校验**：BSM 算出 C ≈ \$10,152.55、P ≈ \$8,671.14 → C − P ≈ \$1,481.4，与平价完全吻合 ✓。`推导`

---

## 8. 常见误区

- ❌ 用平价解释偏离却忽略 `r`/`F` 取值 → 多数"套利"是参数错（见 [09/03](../09-加密期权专题/03-无风险利率r的选取.md)）。
- ❌ 把欧式平价套到美式 → 美式只有边界不等式。
- ❌ 忘了 `q`（ETH 质押）→ 漏项导致等式对不上。
- ❌ 无视交易成本 → 现实是区间，微小偏离未必可套利。
- ❌ 以为平价能定 Call 单价 → 它只锁 $C-P$ ，单价要模型。
