# Black-Scholes-Merton 模型：公式、推导直觉与各项含义

> BSM 是二叉树**步数趋于无穷的连续极限**。本篇给出假设、公式、**每一项的金融含义**，并从"风险中性期望"和"对数正态分布"出发**推导 d₁/d₂ 的来历**，最后给出由公式直接得到的希腊字母，以及它在加密里被违反得有多严重。

## 1. 假设（也是它的软肋）

BSM 成立依赖一组理想化假设：

1. 标的服从**几何布朗运动（GBM）**：`dS = μS\,dt + σS\,dW`，对数收益正态、**波动率 σ 恒定**。
2. 无风险利率 `r` 恒定、可自由借贷。
3. 无摩擦：无手续费/税、可连续交易、可卖空。
4. 无套利。
5. 欧式、标的无离散跳跃。

> 这些假设**加密几乎条条被挑战**（σ 不恒定且有微笑、价格跳跃/清算、r 是会动的基差）。见 §6。

---

## 2. 公式

含持有收益 `q`（股息 / ETH 质押）的一般式：

$$ \boxed{\;C = S e^{-q\tau} N(d_1) - K e^{-r\tau} N(d_2)\;} $$
$$ \boxed{\;P = K e^{-r\tau} N(-d_2) - S e^{-q\tau} N(-d_1)\;} $$

$$ d_1 = \frac{\ln(S/K) + (r - q + \tfrac{1}{2}\sigma^2)\tau}{\sigma\sqrt{\tau}},\qquad d_2 = d_1 - \sigma\sqrt{\tau} $$

`N(·)` 为标准正态累积分布函数。（`q=0` 即无收益情形。）

---

## 3. 推导直觉：风险中性期望 + 对数正态 `推导`

延续二叉树的结论——**定价 = 风险中性期望的折现**：

$$ C = e^{-r\tau}\,\mathbb{E}^{Q}\!\big[\max(S_T - K,\,0)\big] $$

在风险中性测度下，GBM 的解使 `S_T` **服从对数正态分布**：

$$ \ln S_T \sim \mathcal{N}\!\Big(\ln S_0 + (r - q - \tfrac{1}{2}\sigma^2)\tau,\;\; \sigma^2\tau\Big) $$

> 注意漂移里是 `r−q−½σ²`（伊藤引理的 `−½σ²` 修正项），而 `d₁` 里却是 `+½σ²`——差别正来自下面对 `S_T·1_{S_T>K}` 求期望时的测度变换，这就是 `d₁`、`d₂` 同时出现的根源。

把期望拆成两块：

$$ C = e^{-r\tau}\Big(\underbrace{\mathbb{E}^{Q}[S_T\,\mathbf{1}_{S_T>K}]}_{\text{得到标的的那部分}} - \underbrace{K\,\mathbb{E}^{Q}[\mathbf{1}_{S_T>K}]}_{\text{付出行权价的那部分}}\Big) $$

- **第二块**：`E^Q[1_{S_T>K}] = Q(S_T>K) = N(d_2)`。把对数正态的 `P(S_T>K)` 标准化即得 `d₂`。
- **第一块**：含 `S_T` 的加权，需做一次测度/变量变换，结果 `E^Q[S_T 1_{S_T>K}] = S_0 e^{(r-q)\tau} N(d_1)`，多出的 `σ²` 把 `d₂` 抬成 `d₁ = d₂ + σ√τ`。

代回并整理即得 §2 的 Call 公式。Put 由[平价公式](./01-平价公式.md) `C − P = Se^{−qτ} − Ke^{−rτ}` 立刻得到。

> 另一条等价路径是解 **Black-Scholes 偏微分方程** `∂V/∂t + ½σ²S²∂²V/∂S² + (r−q)S∂V/∂S − rV = 0`（由 Delta 对冲构造无风险组合得到）——它正是 [Gamma–Theta 对偶](../02-希腊字母/03-Theta.md) 的来源。

---

## 4. 每一项的含义

以 Call 为例：

| 项 | 含义 |
|---|---|
| `N(d_2)` | **风险中性下到期实值的概率** `Q(S_T>K)` |
| `K e^{-r\tau} N(d_2)` | 行权要付的 `K` 的现值 ×（要付的概率） |
| `N(d_1)` | 与 **Delta** 直接相关：`Δ_call = e^{-qτ}N(d_1)` |
| `S e^{-q\tau} N(d_1)` | 行权才拿到的标的的现值（按拿到的"风险调整"权重） |
| `σ√τ` | 总波动量；`d_1−d_2` 就等于它 |

> 回扣 [Delta 篇](../02-希腊字母/01-Delta.md) 的"Δ≈到期实值概率"：更精确说，**Call 的 Delta = N(d₁)**，而**到期实值概率 = N(d₂)**，两者相差 `σ√τ`，深虚/长到期时差距明显。

---

## 5. 由公式直接得到的希腊字母 `公认结论`

BSM 给出希腊字母的闭式解（设 `n(·)` 为标准正态密度，下为含 `q` 形式）：

| 希腊字母 | Call 表达式 |
|---|---|
| Delta | `e^{-qτ} N(d_1)` |
| Gamma | `\dfrac{e^{-qτ} n(d_1)}{S\,σ\sqrt{τ}}`（Call/Put 相同） |
| Vega | `S e^{-qτ} n(d_1)\sqrt{τ}`（Call/Put 相同，恒正） |
| Theta | 含 `−\dfrac{S e^{-qτ} n(d_1)σ}{2\sqrt{τ}}` 等项 |
| Rho | `K τ e^{-rτ} N(d_2)` |

- **Gamma、Vega 在 Call/Put 相同且恒正** → 印证 [02 章](../02-希腊字母/06-组合希腊字母与关系.md) 的结论。
- Gamma 分母含 `σ√τ`、Vega 含 `√τ` → 解释"短到期 Gamma 大、长到期 Vega 大"。

## 6. 加密视角：BSM 被违反得有多狠

| BSM 假设 | 加密现实 | 影响 |
|---|---|---|
| σ 恒定 | **波动率微笑/曲面 + DVOL 剧变** | 单一 σ 不够，要用 [波动率曲面](../04-波动率/) |
| 对数正态、无跳 | **跳跃 + 清算级联**（[09/04](../09-加密期权专题/04-DVOL与加密波动率特征.md)） | 尾部比对数正态厚得多，深虚值被低估 |
| r 恒定且无风险 | `r`=会动的**基差/资金费率**（[09/03](../09-加密期权专题/03-无风险利率r的选取.md)） | 用市场远期反推 r |
| 连续交易 | 7×24 但仍有跳空 | 对冲不可能完美连续 |
| 标准结算 | **币本位非线性**（[09/01](../09-加密期权专题/01-币本位与反向合约.md)） | 不在标准 BSM 框架内 |

> 实务里 BSM 更多被当作**报价语言**：用它把价格翻译成 IV，再在[波动率曲面](../04-波动率/)上比较，而不是当成"真理价格"。

## 7. 算例：给同一张 BTC ATM Call 定价

`S=60,000`、`K=60,000`、`τ=0.25`、`σ=80%`、`r=10%`、`q=0`。

**d₁、d₂**（`σ²/2 = 0.32`）：
$$ d_1=\frac{0 + (0.1 + 0.32)\times0.25}{0.8\times0.5}=\frac{0.105}{0.4}=0.2625,\quad d_2=0.2625-0.4=-0.1375 $$

**正态值**：`N(0.2625)≈0.6035`，`N(−0.1375)≈0.4453`。`待核实`（查表近似）

**价格**：
$$ C = 60{,}000\times0.6035 - 60{,}000\,e^{-0.025}\times0.4453 = 36{,}210 - 26{,}058 \approx \boxed{\$10{,}150} $$

- 对照 [二叉树单步](./02-二叉树模型.md) 的 \$12,439：**单步太粗，BSM（=无穷步极限）给出约 \$10,150**，多步二叉树会收敛到这个值。
- 验证平价：`C−P = S−Ke^{−rτ}=1,481`（与 [01-平价](./01-平价公式.md) 算例一致）→ `P≈8,669`。`推导`

## 8. 常见误区

- ❌ 把 BSM 当"真实价格" → 它是一组强假设下的模型，加密里更像报价/IV 翻译器。
- ❌ 用单一 σ 给所有行权价定价 → 现实有微笑，需曲面。
- ❌ 混淆 `N(d₁)` 与 `N(d₂)` → 前者是 Delta、后者是实值概率，差 `σ√τ`。
- ❌ 在加密直接套美债 r、忽略币本位非线性 → 见 09/01、09/03。
