# Black-Scholes-Merton 模型：公式、推导与各项含义

> **一句话总览**：BSM 是二叉树步数趋于无穷的**连续极限**，用"**风险中性期望折现**"给欧式期权一个唯一的无套利价。核心： $C = S e^{-q\tau} N(d_1) - K e^{-r\tau} N(d_2)$ 。在加密里它更像**报价 / IV 翻译器**，而非"真理价格"（假设几乎条条被违反）。

| $d_1,\ d_2$ | 见下 | — |

## 2. 直觉 / 类比

把 [二叉树](./02-二叉树模型.md) 的步数推到无穷，就得到 BSM。它的灵魂是：**用复制组合把方向风险对冲掉之后，期权价 = 在"风险中性测度"下到期赔付的期望，再贴现到今天**。

$$ C = e^{-r\tau}\,\mathbb{E}^{Q}\!\big[\max(S_T - K,\ 0)\big] $$

"风险中性"不是说投资者真的中性，而是对冲掉风险后，定价**只剩贴现的期望赔付**，与标的真实涨跌概率无关（见 [二叉树篇](./02-二叉树模型.md)）。

## 3. 定义

**BSM 价**：在下列假设下，欧式期权的唯一无套利价格。含持有收益 $q$ 的一般式：

$$ \boxed{\ C = S e^{-q\tau} N(d_1) - K e^{-r\tau} N(d_2)\ } $$
$$ \boxed{\ P = K e^{-r\tau} N(-d_2) - S e^{-q\tau} N(-d_1)\ } $$
$$ d_1 = \frac{\ln(S/K) + (r - q + \tfrac{1}{2}\sigma^2)\tau}{\sigma\sqrt{\tau}},\qquad d_2 = d_1 - \sigma\sqrt{\tau} $$

其中 $N(\cdot)$ 是标准正态累积分布函数（ $q=0$ 即无收益情形）。

## 4. 公式与推导

**假设**（也是软肋，标 `公认结论`）：① 标的服从几何布朗运动（GBM），对数收益正态、 $\sigma$ **恒定**；② $r$ 恒定可自由借贷；③ 无摩擦、可连续交易、可卖空；④ 无套利；⑤ 欧式、无跳跃。

**逐步推导**（风险中性期望 + 对数正态）`推导`：

**① 定价 = 风险中性期望折现**（承二叉树）：

$$ C = e^{-r\tau}\,\mathbb{E}^{Q}\!\big[\max(S_T - K,\ 0)\big] $$

**② 风险中性下 $S_T$ 服从对数正态**（GBM 解 + 伊藤的 $-\tfrac{1}{2}\sigma^2$ 修正）：

$$ \ln S_T \sim \mathcal{N}\!\Big(\ln S + (r - q - \tfrac{1}{2}\sigma^2)\tau,\ \ \sigma^2\tau\Big) $$

**③ 拆成两块**（赔付 = 拿到标的 − 付出行权价，仅在实值时）：

$$ C = e^{-r\tau}\Big( \mathbb{E}^{Q}[S_T\,\mathbf{1}_{S_T>K}] - K\,\mathbb{E}^{Q}[\mathbf{1}_{S_T>K}] \Big) $$

**④ 第二块** = 实值概率： $\mathbb{E}^{Q}[\mathbf{1}_{S_T>K}] = Q(S_T>K) = N(d_2)$ （把对数正态标准化即得 $d_2$ ）。

**⑤ 第一块** 含 $S_T$ 权重，做一次测度/变量变换得 $\mathbb{E}^{Q}[S_T\,\mathbf{1}_{S_T>K}] = S e^{(r-q)\tau} N(d_1)$ ；多出的 $\sigma^2$ 把 $d_2$ 抬成 $d_1 = d_2 + \sigma\sqrt{\tau}$ 。

**⑥ 代回整理** 即得 §3 的 Call 公式；Put 由 [平价公式](./01-平价公式.md) $C - P = S e^{-q\tau} - K e^{-r\tau}$ 直接得到。

> 注意第 ② 步漂移里是 $-\tfrac{1}{2}\sigma^2$ ，而 $d_1$ 里是 $+\tfrac{1}{2}\sigma^2$ ——差别正来自第 ⑤ 步对 $S_T \mathbf{1}_{S_T>K}$ 求期望的测度变换，这就是 $d_1,\ d_2$ 同时出现的根源。

**各项含义**： $N(d_2)$ = 风险中性下到期实值概率； $K e^{-r\tau} N(d_2)$ = 要付的行权价现值 ×（要付的概率）； $S e^{-q\tau} N(d_1)$ = 拿到标的的"风险调整"现值； $\sigma\sqrt{\tau}$ = 总波动量（ $d_1 - d_2$ ）。

> 等价路径：解 **Black-Scholes 偏微分方程** $\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + (r-q) S \frac{\partial V}{\partial S} - rV = 0$ （由 Delta 对冲构造无风险组合得到）——它正是 [Gamma–Theta 对偶](../02-希腊字母/03-Theta.md) 的来源。

## 5. 特例与极限检验

用边界验证公式（专家自检）：

- **临到期**（ $\tau \to 0$ ）： $d_1,\ d_2 \to \pm\infty$ ， $C \to \max(S - K,\ 0)$ ——退化为内在价值。✓
- **无波动**（ $\sigma \to 0$ ）： $C \to \max\!\big(S e^{-q\tau} - K e^{-r\tau},\ 0\big)$ ——贴现远期的内在价值。✓
- **深实值（ $S \gg K$ ）**： $N(d_1), N(d_2) \to 1$ ， $C \to S e^{-q\tau} - K e^{-r\tau}$ （近似远期）。✓
- **深虚值（ $S \ll K$ ）**： $N \to 0$ ， $C \to 0$ 。✓
- **平价自检**： $C - P = S e^{-q\tau} - K e^{-r\tau}$ （与 [01 平价](./01-平价公式.md) 一致）。✓

## 6. 敏感度 / 希腊字母（闭式）`公认结论`

| 希腊字母 | Call 闭式 | 方向 |
|---|---|---|
| Delta | $e^{-q\tau} N(d_1)$ | $S\uparrow \Rightarrow C\uparrow$ |
| Gamma | $\dfrac{e^{-q\tau} n(d_1)}{S\,\sigma\sqrt{\tau}}$ （Call/Put 同） | 恒正 |
| Vega | $S e^{-q\tau} n(d_1)\sqrt{\tau}$ （Call/Put 同） | $\sigma\uparrow \Rightarrow$ 价↑ |
| Theta | 含 $-\dfrac{S e^{-q\tau} n(d_1)\sigma}{2\sqrt{\tau}}$ 等项 | 多头通常 <0 |
| Rho | $K \tau e^{-r\tau} N(d_2)$ | $r\uparrow \Rightarrow C\uparrow$ |

- Gamma 分母含 $\sigma\sqrt{\tau}$ 、Vega 含 $\sqrt{\tau}$ → 解释"短到期 Gamma 大、长到期 Vega 大"（[02 章](../02-希腊字母/06-组合希腊字母与关系.md)）。

## 7. 算例（详细）

**参数**：

| 参数 | 取值 |
|---|---|
| $S$ | 60,000 |
| $K$ | 60,000（ATM） |
| $\tau$ | 0.25 |
| $\sigma$ | 0.80 |
| $r$ | 0.10 |
| $q$ | 0 |

**逐步代入**（ $\sigma^2/2 = 0.32$ ）：

$$ d_1 = \frac{\ln(60{,}000/60{,}000) + (0.10 + 0.32)\cdot 0.25}{0.80\sqrt{0.25}} = \frac{0 + 0.105}{0.40} = 0.2625 $$
$$ d_2 = 0.2625 - 0.80\sqrt{0.25} = 0.2625 - 0.40 = -0.1375 $$

查表： $N(0.2625) \approx 0.6035$ ， $N(-0.1375) \approx 0.4453$ `待核实`（查表近似）。

$$ C = 60{,}000 \cdot 0.6035 - 60{,}000\, e^{-0.025} \cdot 0.4453 = 36{,}210 - 26{,}058 \approx 10{,}150 $$

**结果与解读**：ATM、年化 80% 波动、3 个月的 BTC 看涨理论价 ≈ \$10,150（约现价的 17%）——加密高 IV 下 ATM 期权很贵。

**币 / USD 双口径**：Deribit 权利金以币计， $C_{\text{BTC}} \approx 10{,}150 / 60{,}000 \approx 0.169$ BTC；到期币本位结算的非线性见 [09/01](../09-加密期权专题/01-币本位与反向合约.md)。

**交叉验证**：
- 对照 [二叉树单步](./02-二叉树模型.md) 的 \$12,439（太粗），多步收敛到 ≈ \$10,150。
- 平价： $C - P = S - K e^{-r\tau} = 60{,}000 - 58{,}519 = 1{,}481$ → $P \approx 8{,}669$ （与 [01 平价](./01-平价公式.md) 算例一致）。`推导`

**工具复算**：`python3 -c "from tools.option_strategy import bsm_price; print(bsm_price(60000,60000,0.25,0.80,0.10,0,'call'))"` → 与上一致（见 [tools/](../../tools/README.md)）。

## 9. 加密 vs 传统：BSM 被违反得有多狠

| BSM 假设 | 加密现实 | 影响 |
|---|---|---|
| $\sigma$ 恒定 | 微笑/曲面 + DVOL 剧变 | 单一 $\sigma$ 不够，要用 [曲面](../04-波动率/) |
| 对数正态、无跳 | 跳跃 + 清算级联（[09/04](../09-加密期权专题/04-DVOL与加密波动率特征.md)） | 尾部更厚，深虚值被低估 |
| $r$ 恒定无风险 | $r$ = 会动的基差/资金费率（[09/03](../09-加密期权专题/03-无风险利率r的选取.md)） | 从远期反推 $r$ |
| 连续交易 | 7×24 但有跳空 | 对冲不可能完美连续 |
| 标准结算 | 币本位非线性（[09/01](../09-加密期权专题/01-币本位与反向合约.md)） | 不在标准框架内 |

## 10. 实操要点 / 应用

- **当报价/IV 翻译器用**：把市场价反解成 [IV](./04-隐含波动率与模型校准.md)，在 [曲面](../04-波动率/03-波动率期限结构与曲面.md) 上比贵贱，而非当"真理价"。
- **先校准** $r$ ：用期货反推（[09/03](../09-加密期权专题/03-无风险利率r的选取.md)），否则理论价系统性偏离盘口。
- **别用单一 $\sigma$ 给所有行权价定价**：用按行权价/到期的 IV。

## 11. 常见误区

- ❌ 把 BSM 当"真实价格" → 它是一组强假设下的模型，加密里更像 IV 翻译器。
- ❌ 混淆 $N(d_1)$ 与 $N(d_2)$ → 前者关联 Delta、后者是实值概率，差 $\sigma\sqrt{\tau}$ 。
- ❌ 用单一 $\sigma$ 给整条链定价 → 现实有微笑。
- ❌ 加密直接套美债 $r$ 、忽略币本位非线性 → 见 09/01、09/03。
