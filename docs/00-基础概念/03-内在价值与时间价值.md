# 内在价值与时间价值（moneyness 深入）

> 上一篇说"权利金 = 内在价值 + 时间价值"。这一篇拆开它：**内在价值是"现在行权值多少"，时间价值是"为还有可能多付的钱"**。理解这个拆分，才能看懂为什么虚值期权会"慢慢归零"、为什么临近到期权利金掉得越来越快。

## 前置知识
- [02-期权四要素](./02-期权四要素.md) — 行权价、moneyness、权利金

---

## 1. 权利金的两块拼图

$$ \text{权利金 } p = \underbrace{\text{内在价值}}_{\text{现在行权值多少}} + \underbrace{\text{时间价值}}_{\text{为"还有可能"多付的}} $$

- **内在价值（Intrinsic Value）**：立刻行权能拿到的钱，**永不为负**。
- **时间价值（Time Value / Extrinsic Value）**：权利金里超出内在价值的部分，**到期归零**。

---

## 2. 内在价值：现在行权值多少

$$ \text{Call 内在} = \max(S - K,\ 0) \qquad \text{Put 内在} = \max(K - S,\ 0) $$

- 只有**实值（ITM）**期权才有内在价值；平值/虚值的内在价值 = 0。
- 它有"地板"：永远 ≥ 0（不行权就好，不会倒亏）。

| moneyness | Call 内在价值 | 含义 |
|---|---|---|
| 实值 ITM（`S>K`） | `S−K` > 0 | 立即行权有赚头 |
| 平值 ATM（`S≈K`） | ≈ 0 | 刚好打平 |
| 虚值 OTM（`S<K`） | 0 | 立即行权一文不值 |

---

## 3. 时间价值：为"还有可能"付的钱

权利金里减掉内在价值，剩下的就是时间价值。它反映**到期前标的还可能朝有利方向变动**的期望价值。

时间价值的三个规律（直觉，量化见 [02-希腊字母](../02-希腊字母/)）：

1. **到期归零**：`τ → 0` 时间价值 → 0；到期只剩内在价值。
2. **平值最大**：时间价值在 **ATM 附近最高**，越深实值/深虚值越小。
   - 深虚值：大概率作废，没人愿多付 → 时间价值小。
   - 深实值：几乎等同持有标的，"可能性溢价"小 → 时间价值小。
3. **波动率越高越值钱**：标的越能"上蹿下跳"，到期前翻盘可能越大 → 时间价值越高（这就是为什么加密期权时间价值厚，见 [09/04 DVOL](../09-加密期权专题/04-DVOL与加密波动率特征.md)）。

---

## 4. 时间衰减（Time Decay / Theta）

时间价值随时间流逝而减少，叫**时间衰减**，对应希腊字母 **Theta（Θ）**：

- **非线性**：平值期权的时间价值大致按 $\sqrt{\tau}$ 衰减 → **越临近到期，掉得越快**（最后几天加速）。
- 对**买方不利**（每天损耗）、对**卖方有利**（每天收租）。

> 这解释了一个常见现象：方向看对了，但**涨得太慢**，时间价值流失把利润吃光，买方还是亏。

---

## 5. 算例：拆解一个权利金（USD 口径）

BTC 现价 `S = 60,000`，看涨 `K = 58,000`，权利金 USD 折算 ≈ \$3,000。

| 组成 | 计算 | 值 |
|---|---|---|
| 内在价值 | `max(60,000 − 58,000, 0)` | **\$2,000** |
| 时间价值 | `3,000 − 2,000` | **\$1,000** |

- 这是**实值（ITM）** Call：\$3,000 里 \$2,000 是"现在就值的"，\$1,000 是"为剩余时间付的"。
- 若到期时 `S_T` 仍 = 60,000：时间价值归零，期权只值内在价值 \$2,000 → 买方亏掉那 \$1,000 时间价值。

> 加密提示：Deribit 权利金以 **BTC** 报价，精确拆解要在币口径做（内在价值也要除以价格换成币），见 [09/01](../09-加密期权专题/01-币本位与反向合约.md)。入门先用 USD 口径理解结构。

---

## 6. 常见误区

- ❌ 以为权利金全是"赌注本身" → 其中内在价值部分是"现值"，不是纯时间博弈。
- ❌ 买深度虚值"便宜" → 便宜=几乎全是时间价值且大概率归零，是高频亏损来源。
- ❌ 方向对就该赚 → 涨太慢时时间价值流失可能盖过方向收益。
- ❌ 以为时间价值匀速流失 → 它是非线性的，临到期加速（尤其 ATM）。
