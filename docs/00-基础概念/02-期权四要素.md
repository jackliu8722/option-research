# 期权四要素：行权价、到期日、权利金、合约乘数

> 上一篇知道了期权是"权利"。这一篇把一张期权报价上的**四个关键数字**逐个讲清，让你能完整读懂"BTC-27JUN25-65000-C @ 0.03"这种合约代码到底说了什么。

## 前置知识
- [01-期权是什么](./01-期权是什么.md) — 权利/义务、看涨/看跌

---

## 1. 一张期权 = 四个要素

任何一张期权由四个要素唯一确定：

| 要素 | 符号 | 含义 |
|---|---|---|
| 标的 + 行权价 | `K` | 约定的买卖价格 |
| 到期日 | `T`（剩余期限 `τ`） | 权利何时失效 |
| 类型 | Call / Put | 买入权 还是 卖出权 |
| 权利金 | `p` | 买方付、卖方收的价格 |
| （第五个）合约乘数 | | 一张合约对应多少标的 |

下面逐个看。

---

## 2. 行权价（Strike, K）

约定的成交价格。它决定期权当前是"价内还是价外"——即 **moneyness（实值/平值/虚值）**：

| 状态 | Call | Put |
|---|---|---|
| 实值 ITM（In the Money） | `S > K` | `S < K` |
| 平值 ATM（At the Money） | `S ≈ K` | `S ≈ K` |
| 虚值 OTM（Out of the Money） | `S < K` | `S > K` |

- 实值 = 现在行权有内在价值；虚值 = 现在行权一文不值（只剩时间价值）。
- 行权价离现价越远（越虚值），权利金越便宜、越像"小赌注"。

> moneyness 与内在/时间价值的细节，见下一篇 `03-内在价值与时间价值`。

---

## 3. 到期日（Expiration, T）

权利失效的时刻。剩余期限 `τ`（通常按年计）越长，时间价值越高。

**行权方式**（在哪些时点能行权）：
- **欧式（European）**：只能在到期日行权。
- **美式（American）**：到期前任意时点都能行权。
- 加密：**Deribit 的 BTC/ETH 期权是欧式、现金交割**；美股个股期权多为美式。`公认结论`（具体以各市场为准）

**加密到期排期**（Deribit）：通常有**日/周/月/季度**多种到期，统一在 **UTC 08:00** 结算。`待核实`（精确排期与结算时间以官网为准）

---

## 4. 权利金（Premium, p）

期权的价格，由两部分组成（下一篇详解）：

$$ \text{权利金} = \text{内在价值} + \text{时间价值} $$

- **内在价值**：立即行权能拿到的部分（`max(S−K,0)` 或 `max(K−S,0)`）。
- **时间价值**：为"还有时间、还有可能"多付的部分；到期归零。

**报价口径**（易踩坑）：
- 美股：权利金以**美元/每股**报价，乘以 100（乘数）= 一张合约成本。
- 加密 Deribit：权利金以**币（BTC/ETH）报价**，界面另显示 USD 折算。例：`0.03` 表示 0.03 BTC。

---

## 5. 合约乘数（Contract Size / Multiplier）

一张合约对应多少标的——直接决定你的真实敞口和成本。**各市场差异大，必须看清**：

| 市场 | 一张合约 = | 备注 |
|---|---|---|
| 美股个股/ETF 期权 | 100 股 | 权利金×100=每张成本 `公认结论` |
| A股 50ETF/300ETF 期权 | 10,000 份 | `公认结论`（以交易所合约为准）`待核实` |
| **加密 Deribit BTC 期权** | **1 BTC** | 币本位结算 `公认结论` |
| 加密 Deribit ETH 期权 | 1 ETH | 同上 |

> 算真实成本/盈亏时**别忘乘数**：美股一张"标价 \$2 的 Call"实际要付 \$200。

---

## 6. 算例：读懂一个合约代码

`BTC-27JUN25-65000-C @ 0.03`

| 字段 | 含义 |
|---|---|
| BTC | 标的：比特币 |
| 27JUN25 | 到期日：2025-06-27（UTC 08:00 结算）|
| 65000 | 行权价 `K = $65,000` |
| C | 类型：Call（看涨）|
| @ 0.03 | 权利金 = 0.03 BTC/张 |

- 一张 = 1 BTC 敞口；权利金 0.03 BTC（设当时 BTC=\$60,000 → ≈ \$1,800）。
- 若现价 \$60,000 < `K`=\$65,000 → 此 Call 当前**虚值（OTM）**，权利金全是时间价值。

---

## 7. 常见误区

- ❌ 忽略合约乘数 → 美股把"\$2"当成总成本（实际 \$200）。
- ❌ 把加密权利金的"0.03"当美元 → 它是 0.03 **BTC**。
- ❌ 以为美式/欧式无所谓 → 影响提前行权、分红/资金费率处理（细节见 01-合约机制）。
- ❌ 只看权利金便宜就买深度虚值 → 便宜是因为大概率到期归零。
