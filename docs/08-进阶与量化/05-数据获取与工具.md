# 数据获取与工具（Data & Tooling）

> 量化期权研究的地基是**干净、对齐、可复现的数据**和**靠谱的工具链**。本篇汇总加密期权常用的数据源与 Python 工具，并强调数据卫生。具体接口/产品以官方为准 `待核实`。

## 前置知识
- [04-回测方法论](./04-回测方法论.md)

---

## 1. 数据源（加密期权）`待核实`

| 来源 | 用途 | 备注 |
|---|---|---|
| **Deribit API** | BTC/ETH 期权报价、希腊字母、**DVOL**、指数、未平仓 | 主力；时区 UTC |
| OKX / Binance / Bybit API | 各自期权/永续数据 | 规格不同，别混用 |
| Laevitas / Amberdata | IV 曲面、skew、未平仓、历史链 | 部分付费 |
| Tardis.dev | 历史 tick / 订单簿 | 高频回测 |
| Glassnode / Coinglass | 链上与衍生品指标、资金费率 | 辅助 |

> 接口字段、限频、历史深度以**各家文档**为准 `待核实`。

---

## 2. 关键数据字段

- **期权链**：行权价、到期、bid/ask/mark、IV、希腊字母、未平仓（OI）、成交量。
- **标的/指数**：现货指数、期货价（用于反推 r/F，[09/03](../09-加密期权专题/03-无风险利率r的选取.md)）。
- **永续**：标记价、资金费率（对冲成本，[09/02](../09-加密期权专题/02-永续合约与资金费率对冲.md)）。
- **波动率指数**：DVOL（[04/04](../04-波动率/04-VIX与DVOL.md)）。

---

## 3. Python 工具链 `公认结论`/`待核实`

- **数据处理**：`numpy`、`pandas`、`scipy`。
- **定价 / IV**：`py_vollib`、`QuantLib`（BSM、希腊字母、IV 反解）`待核实`。
- **曲面 / 拟合**：自实现 SVI 或现成库；`scipy.optimize` 做校准。
- **可视化**：`matplotlib`、`plotly`（盈亏图、曲面）。
- **回测**：自建事件驱动框架（期权需链级回放，多数通用框架不直接支持）。

---

## 4. 数据卫生（必须做）

- **时区统一 UTC**，期权链与标的**同一时间戳对齐**（[04 回测](./04-回测方法论.md)）。
- **口径一致**：r/F、币本位、年化 $\sqrt{365}$ 全程一致。
- **过滤坏报价**：剔除宽价差/零成交/陈旧 mark；无套利检查（[03 曲面](./03-波动率曲面建模与无套利.md)）。
- **记录来源与版本**：数据快照日期、接口版本、随机种子 → 可复现。

---

## 5. 一个最小研究栈（示例）

1. 拉 Deribit 期权链 + 指数 + 期货（UTC 对齐）。
2. 校准 F/r → 反解 IV → 拟合并无套利检查曲面。
3. 计算 RV、DVOL 分位、IV−RV 价差等信号。
4. 事件驱动回测，建入手续费/滑点/funding。
5. 报告回撤/尾部/单位风险收益，归档可复现。

---

## 6. 常见误区

- ❌ 混用不同交易所口径。
- ❌ 不对齐时间戳。
- ❌ 用 mark/mid 当可成交价。
- ❌ 不记录数据版本 → 无法复现。
