期权风险的"仪表盘"。理解每个希腊字母衡量什么风险、如何相互作用。

## 计划笔记
- Delta：方向敞口；与对冲的关系（✅ 见上）
- Gamma：Delta 的变化率；为什么临近到期/平值时最大
- Theta：时间衰减；买方/卖方的对立
- Vega：对隐含波动率的敏感度
- Rho：利率敏感度（加密中 r 的特殊性）
- 希腊字母之间的关系与组合希腊字母
- 加密视角：币本位下的 Delta/Gamma 实际敞口换算
