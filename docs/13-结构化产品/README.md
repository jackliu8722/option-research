# 13 · 结构化产品

加密零售最常碰、也最容易被"高年化"误导的一章。核心一句话：**每个结构化产品都 = 债券/现金 + 期权头寸；所谓"收益/增强"就是你在卖（或买）期权**。学会拆解，就看穿了真实风险。

> 把前面的积木（[备兑/卖权](../05-基础策略/)、[障碍](../12-奇异期权/02-障碍期权.md)、[二元](../12-奇异期权/01-二元数字期权.md)、[VRP](../08-进阶与量化/02-已实现与隐含波动率价差.md)）拼起来。可数值验证处用 [`tools/option_strategy.py`](../../tools/option_strategy.py) 复算。

## 已完成
- [01 · 双币理财 DCI](./01-双币理财DCI.md) — = 现金担保卖 Put / 备兑卖 Call；高年化的真相是**卖波动率收权利金**；风险=暴跌被行权（含 80% 年化算例）
- [02 · 雪球与 Autocall](./02-雪球与Autocall.md) — = 卖 down-and-in put + 敲出封顶 + 票息；**高息票据的真相是卖崩盘保险**；负偏赔付、加密厚尾尤危（四情景表）
- [03 · 鲨鱼鳍与保本票据](./03-鲨鱼鳍与保本票据.md) — PPN = 零息债 + 期权；鲨鱼鳍 = 保本 + 敲出期权；**加密陷阱：保的是币还是美元**（含保本预算算例）

## 一句话总结
- 卖方型（你收权利金、担风险）：DCI、雪球。
- 买方型（你付利息、博收益）：保本票据、鲨鱼鳍。
