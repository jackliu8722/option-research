# 14 · 数值方法与实现

没有解析解时怎么定价？三大数值武器：**蒙特卡洛**（模拟路径，主攻路径依赖/高维）、**有限差分**（解 PDE，主攻美式/障碍）、**傅里叶/FFT**（特征函数反演，主攻 Heston/Bates 校准）。本章把前面的模型落到"可跑的代码"。

> 三种方法都已在 [`tools/option_strategy.py`](../../tools/option_strategy.py) 实现（`mc_price` / `fd_price` / `fourier_call`），并验证收敛到 BSM 标杆。

## 已完成
- [01 · 蒙特卡洛](./01-蒙特卡洛.md) — 模拟终值/路径、误差 $M^{-1/2}$ 、方差缩减（对偶/控制变量）、路径依赖主力（MC≈BSM 0.16%）
- [02 · 有限差分（PDE）](./02-有限差分PDE.md) — BSM 方程离散、显式/隐式/Crank-Nicolson、美式/障碍主力、网格读 Greeks（FD≈BSM 0.04%）
- [03 · 傅里叶/FFT 定价](./03-傅里叶FFT定价.md) — 特征函数 + Gil-Pelaez/Carr-Madan、Heston/Bates 校准标准管线（傅里叶=BSM 精确）

## 三选一
| 需求 | 方法 |
|---|---|
| 欧式 + 有特征函数（Heston/Bates） | 傅里叶/FFT |
| 美式 / 障碍 / 低维 | 有限差分 |
| 路径依赖 / 高维 | 蒙特卡洛 |
