# 加密特有风险（综合）

> 收尾加密专题：把分散在各篇的"加密比传统更危险的地方"汇成一张清单，每条指向详解。**通用理论照搬到加密最容易在这些点出错。**

## 1. 七类加密特有风险

| 风险 | 一句话 | 详解 |
|---|---|---|
| **币本位非线性** | 盈亏/保证金以币计，对美元非线性，Call 以币封顶 | [01](./01-币本位与反向合约.md)、[07 单位篇](../02-希腊字母/07-币本位希腊字母的单位与换算.md) |
| **清算级联** | 杠杆强平 → 价格跳动 → 更多强平，已实现波动尖峰 | [04](./04-DVOL与加密波动率特征.md)、[07/03 压力测试](../07-风险管理/03-尾部风险与压力测试.md) |
| **无公认无风险利率** | r 是会动的基差/资金费率，取错则定价偏 | [03](./03-无风险利率r的选取.md) |
| **资金费率/基差波动** | 对冲成本/收益不稳定，可反号 | [02](./02-永续合约与资金费率对冲.md) |
| **平台/对手方** | 交易所破产/宕机/被盗、提现冻结 | [07/04](../07-风险管理/04-对手方与平台风险.md) |
| **稳定币脱锚** | U 本位保证金/结算受冲击 | [07/04](../07-风险管理/04-对手方与平台风险.md) |

---

## 2. 为什么这些在加密更严重

- **7×24 + 无熔断**：跳空随时发生，无法假设能及时止损/对冲（[01/04 市场对照](../01-合约与机制/04-各市场规则对照.md)）。
- **高杠杆 + 清算机制**：放大尾部，制造级联。
- **监管/基础设施不成熟**：平台、稳定币、预言机都是额外单点。
- **IV 量级高**：同样策略的希腊字母绝对冲击更大（[04 DVOL](./04-DVOL与加密波动率特征.md)）。

---

## 3. 综合缓解原则

- **限险结构优先**：价差/铁鹰替代裸卖（[06/05 选择框架](../06-组合策略/05-组合策略选择框架.md)）。
- **统一口径**：币/USD 双口径记账，按 USD 净敞口对冲（[07 单位篇](../02-希腊字母/07-币本位希腊字母的单位与换算.md)）。
- **极端压力测试 + 清算缓冲**：用加密量级的价格/IV 冲击（[07/03](../07-风险管理/03-尾部风险与压力测试.md)）。
- **分散平台、控制单点、关注稳定币/预言机健康**（[07/04](../07-风险管理/04-对手方与平台风险.md)）。
- **把 funding/基差纳入收益核算**（[02](./02-永续合约与资金费率对冲.md)、[03](./03-无风险利率r的选取.md)）。

---

## 4. 常见误区（汇总）

- ❌ 用传统线性盈亏/利率/对冲直觉套加密。
- ❌ 只管市场风险，忽略平台/预言机/脱锚。
- ❌ 裸卖收租不限险、不留清算缓冲。
- ❌ 压力测试用传统温和网格。
