# 链上期权（On-chain / DeFi Options）

> 链上期权把定价、做市、结算、清算都搬到智能合约上。它带来自托管与透明，也带来 CEX 没有的风险：**AMM 库存风险、预言机、合约漏洞、gas/MEV**。机制演化很快，具体协议以官方为准 `待核实`。

## 1. 两种范式

- **AMM 做市**：流动性池被动做市，合约按模型（常基于 BSM + 调整）报价、自动成交。
- **链上订单簿 / 混合**：撮合在链上或链下、结算上链。

> 早期以 AMM 为主（解决冷启动流动性）；成熟后向订单簿/混合演进 `待核实`。

---

## 2. AMM 定价怎么做 `待核实`

- 多以 **Black-Scholes 为基**，输入预言机喂的现货价与一个波动率参数，再按**池库存/偏斜**动态调整买卖价（库存越偏、报价越偏）。
- **波动率**可能由治理设定、外部喂价或自适应机制给出（不像 CEX 由订单流内生）。
- 结果：报价**滞后/偏离** CEX 公平价的可能更大，套利者来对齐。

---

## 3. 流动性提供者（LP）的风险

- LP 相当于**被动卖方/对手方**：用户赚的钱可能就是 LP 亏的。
- 类似"逆向选择"：信息灵的交易者占 LP 便宜。
- 协议常用**对冲机制 / 费用 / 偏斜**保护 LP，但极端行情下 LP 仍可能大亏。
- 与现货 AMM 的"无常损失"不同，期权 LP 承担的是**期权空头的非线性风险**。

---

## 4. 结算、预言机与清算

- **预言机喂价**决定行权结算与清算触发 → 预言机延迟/被操纵是核心风险（[07/04](../07-风险管理/04-对手方与平台风险.md)）。
- **链上清算**：抵押不足被合约清算，极端行情 + 网络拥堵时可能失灵或滑点巨大。
- 结算上链 → 不可篡改但受 gas/拥堵影响。

---

## 5. Gas、MEV 与执行

- **Gas**：每次操作有链上费用，拥堵时高 → 高频对冲不划算。
- **MEV / 抢跑**：交易在内存池可见，可能被抢跑或夹击，影响成交价。
- 这些让链上**动态对冲成本**远高于 CEX。

---

## 6. 优缺点对照

| | 链上（DeFi） | CEX（如 Deribit） |
|---|---|---|
| 托管 | **自托管**、透明 | 交易所托管 |
| 流动性 | 较浅、滑点大 | 深、价差小 |
| 风险 | 合约/预言机/gas/MEV | 平台/对手方 |
| 定价 | 模型+池，易偏离 | 订单流内生、较公平 |
| 适合 | 抗审查、链上原生 | 机构、复杂/大额策略 |

---

## 7. 常见误区

- ❌ 把链上当"无风险透明" → 合约/预言机/流动性风险很实在。
- ❌ 假设链上报价=公平价 → 可能滞后/偏离，需套利对齐。
- ❌ 忽略 gas/MEV → 链上对冲成本被低估。
- ❌ 把期权 LP 当"稳定挖矿收益" → 承担期权空头非线性风险。
