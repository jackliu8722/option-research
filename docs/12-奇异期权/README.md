# 12 · 奇异期权（Exotics）

赔付不再只看到期价的期权。三大类：**二元**（全有或全无）、**障碍**（触发即敲入/敲出）、**路径依赖**（亚式看平均、回望看极值）。它们是 [结构化产品](../13-结构化产品/) 的积木，也最考验对冲。

> A 档：可数值验证的关系（二元=窄价差极限、障碍 in-out 平价、亚式<vanilla<回望）已用 [`tools/option_strategy.py`](../../tools/option_strategy.py)（闭式 + 蒙特卡洛）复算。
