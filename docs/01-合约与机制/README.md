## 计划笔记
- 合约规格：乘数、最小变动、报价单位
- 行权方式：欧式 vs 美式；行权与指派（assignment）
- 交割方式：现金交割 vs 实物交割
- 保证金机制：买方/卖方、组合保证金
- 各市场对照：加密(Deribit) / 美股 / A股(50ETF/300ETF)
- 加密专属：币本位 vs U 本位、反向合约的盈亏与保证金、指数价格与预言机结算
