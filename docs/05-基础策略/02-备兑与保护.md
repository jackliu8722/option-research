# 备兑与保护：Covered Call 与 Protective Put

> 把"**持有标的**"和"一条期权腿"组合，就得到两个最常用的基础策略：**备兑开仓（Covered Call）= 持标的 + 卖 Call**（收租、封顶上行）；**保护性看跌（Protective Put）= 持标的 + 买 Put**（买保险、托底下行）。它们也是 [裸卖看涨](../../strategies/卖出看涨-short-call.md) 的限险正解之一。

- [01-单腿策略](./01-单腿策略.md)

## 1. 两个组合一眼看懂

| 策略 | 构成 | 目的 | 代价 |
|---|---|---|---|
| **备兑 Covered Call** | 持标的 + **卖** 1 张 Call | 收权利金、增厚收益、缓冲小跌 | **放弃** $K$ 以上的上行 |
| **保护性看跌 Protective Put** | 持标的 + **买** 1 张 Put | 给下行**买保险**、托底 | 付权利金（拖累收益） |

- 备兑：愿意在 $K$ 减持、换取现在的权利金 → "收租"。
- 保护：愿意付保费、换取下行有底 → "买险"。

---

## 2. 合成本质（用平价公式看穿）`公认结论`

由 [平价公式](../03-定价模型/01-平价公式.md) $C-P=S-Ke^{-r\tau}$ 移项：

- **备兑（持标的 + 卖 Call）≈ 卖 Put**：盈亏形状与 [卖出看跌](../../strategies/卖出看跌-short-put.md) 相同（上行封顶、下行承担）。
- **保护（持标的 + 买 Put）≈ 买 Call**：盈亏形状与 [买入看涨](../../strategies/买入看涨-long-call.md) 相同（下行有底、上行敞开）。

> 这解释了为什么"备兑收租但怕大跌"（像卖 Put）、"保护像买 Call 但更贵"（你先持了标的）。

---

## 3. 盈亏与希腊字母（USD 直觉）

| | 备兑 Covered Call | 保护 Protective Put |
|---|---|---|
| 最大盈利 | $(K-S_0)+p$ （涨到 $K$ 封顶） | 大（标的涨，扣保费） |
| 最大亏损 | 大（标的跌，被权利金部分缓冲） | **有底**：约 $S_0-K+p$ |
| 净 Delta | 正、但 < 1（卖 Call 削顶） | 正、< 1（买 Put 托底） |
| Gamma | 负（来自空头 Call） | 正（来自多头 Put） |
| Theta | **正**（收租） | 负（付保费） |
| Vega | 负 | 正 |

---

## 4. 何时用

- **备兑**：温和看涨/看平、**愿在 $K$ 减持**、想在高 IV 时收租增厚持仓收益；不适合预期暴涨（会踏空上行）。
- **保护**：持有标的但担心尾部下跌、愿付保费买安心；IV 低时保险便宜、更划算。
- **领口 Collar（延伸）**：买 Put 的钱用卖 Call 来出 → **保护性看跌 + 备兑** 叠加，低成本锁定区间（后续可单列）。

---

## 5. 加密视角

- "**持标的**"在加密 = 持现货 BTC/ETH **或** 多头永续（[09/02](../09-加密期权专题/02-永续合约与资金费率对冲.md)，注意资金费率成本）。
- **币本位**：在 Deribit 持 BTC 同时卖 BTC Call（备兑），权利金与盈亏都在币口径，封顶收益也以币计（[09/01](../09-加密期权专题/01-币本位与反向合约.md)）。
- **高 IV** 让备兑的租金厚（利好），但同样意味着标的可能大动——备兑缓冲有限、保护更值。
- 备兑是 [裸卖看涨](../../strategies/卖出看涨-short-call.md) 的限险化：有标的兜着，上行不再"无限亏"，而是"踏空封顶"。

---

## 6. 常见误区

- ❌ 把备兑当"稳收租无风险" → 它本质像卖 Put，大跌照样亏（只被权利金缓冲一点）。
- ❌ 备兑选太近的 $K$ → 收租多但极易被行权、踏空上行。
- ❌ 保护买太贵/太频 → 长期保费拖垮收益；IV 高时尤其。
- ❌ 用永续当"持标的"却忽略资金费率 → 多头永续长期可能持续付 funding。
