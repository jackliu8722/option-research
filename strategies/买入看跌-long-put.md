# 买入看跌（Long Put）

## 1. 一句话定义 + 市场观点
- **定义**：支付权利金，买入"以行权价 $K$ 卖出标的"的权利。
- **观点**：方向**看跌**（或为现货**买保险**）+ 波动率看升/不崩。亏损封顶，是给多头仓位上保险的标准工具。

## 2. 构建方式
- 买入 1 张看跌：选定 $K$ 与到期。
- **行权价**：越虚值（$K$ 越低）越便宜、保护越浅；ATM/实值保护更足但更贵。
- **作保险用**：$K$ 选在你能接受的最大回撤位，到期覆盖风险窗口。
- **加密**：Deribit 欧式、币本位结算（[09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)）。

## 3. 盈亏结构（USD 口径直觉）
- **最大亏损**：权利金 $p$（封顶）。
- **最大盈利**：$K-p$（标的 →0）。
- **盈亏平衡**：USD 约 $K-p$；币本位见 §8。
- **形状**：上方平坦（亏 $p$），跌破 $K$ 后向上。

## 4. 希腊字母特征
| 希腊字母 | 符号 | 含义 |
|---|---|---|
| Delta | − | 看跌方向敞口（−1→0） |
| Gamma | + | 多头凸性，大跌有利 |
| Theta | − | 每天付时间租 |
| Vega | + | IV 升值钱（暴跌常伴 IV 升，双重利好） |

## 5. 适用 / 不适用场景
- **适用**：看跌；给现货/多头**对冲尾部**；预期 IV 升。
- **不适用**：横盘或缓涨（Theta 吃光）；IV 已高（事后 vol crush）。

## 6. 主要风险与常见亏损方式
- **时间衰减 + vol crush**：不跌或跌太慢 → 亏权利金。
- **全损**：到期虚值（$S_T>K$）→ 损失 $p$。
- **币本位**：Put 的 BTC 收益在暴跌时反而**放大**（payoff 含 $S_T^{-1}$ 因子，[09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)）——做保险时实际保护强弱与 USD 直觉不同。

## 7. 调整与离场
- **止盈**：标的已大跌、Delta 接近 −1 时了结。
- **Roll down/out**：下移行权价锁利或展期。
- **保险滚动**：作长期对冲时，到期前 roll 到新周期。

## 8. 算例（Deribit BTC）
参数：$S_0=60{,}000$，$K=55{,}000$，权利金 $p=0.025$ BTC（≈ \$1{,}500）。

| 到期 $S_T$ | USD 内在价值 | BTC payoff = 内在/$S_T$ | BTC 盈亏 = payoff − 0.025 |
|---|---|---|---|
| 60,000 | 0 | 0 | −0.025 BTC（全损） |
| 55,000 | 0 | 0 | −0.025 BTC |
| 50,000 | 5,000 | 0.1000 | +0.0750 BTC |
| 45,000 | 10,000 | 0.2222 | +0.1972 BTC |

- **币本位盈亏平衡**：$K/S_T = 1+0.025 = 1.025$，解得 $S_T = 55{,}000/1.025 \approx 53{,}659$。
- USD 直觉平衡 ≈ 55,000 − 1,500 = 53,500；币本位略低。`推导`（示意）
