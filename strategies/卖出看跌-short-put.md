# 卖出看跌（Short Put）

> 卖出看跌 = "收权利金，愿意在 $K$ 接货"。比裸卖看涨**亏损有上限**（标的最多跌到 0），但加密暴跌又快又深，下行风险仍要认真管理。

## 1. 一句话定义 + 市场观点
- **定义**：收取权利金，承担"被买方按 $K$ 卖给你标的"的义务（即在 $K$ 接货）。
- **观点**：方向**看不跌/小涨** + 波动率**看降**（卖高 IV）。

## 2. 构建方式
- 卖出 1 张看跌：收权利金 $p$ 。
- **现金/保证金担保（cash-secured）**：预留在 $K$ 接货所需资金，避免被强平。
- **价差化**：再买一张更低行权价 Put → **牛市看跌价差**，亏损封顶。
- **加密**：Deribit 币本位保证金；暴跌时清算风险高。

## 3. 盈亏结构（USD 口径直觉）
- **最大盈利**：权利金 $p$ （标的 ≥ $K$ 时全收）。
- **最大亏损**： $K-p$ （标的 →0）。
- **盈亏平衡**：约 $K-p$ 。
- **形状**：下方亏损放大（到 $K-p$ 封顶）， $K$ 之上平坦赚 $p$ 。

## 4. 希腊字母特征
| 希腊字母 | 符号 | 含义 |
|---|---|---|
| Delta | + | 标的跌则亏 |
| Gamma | − | 空头凸性，大跌受伤 |
| Theta | + | 每天收时间租 |
| Vega | − | IV 升则亏 |

## 5. 适用 / 不适用场景
- **适用**：中性偏多、愿在 $K$ 接货、IV 高位收租；常用于"想低位买入又先收笔权利金"。
- **不适用**：看大跌；无力接货/无担保资金；低 IV。

## 6. 主要风险与常见亏损方式
- **暴跌大亏**：加密崩盘又急又深 → 接近 $K-p$ 上限的亏损很快兑现。
- **清算**：保证金不足被强平，失去"接货"选择权。
- **Gamma/Vega 反噬**：临到期平值、IV 跳升时损失加速。

## 7. 调整与离场
- **Roll down/out**：下移行权价、展期降低被行权概率。
- **接货**：被行权即按 $K$ 持有标的（可转备兑继续收租）。
- **价差化/止损**：买更低 Put 限险，或破位买回。

## 8. 算例（Deribit BTC）
参数： $S_0=60{,}000$ ， $K=55{,}000$ ，权利金 $p=0.025$ BTC（≈ \$1{,}500）。

| 到期 $S_T$ | USD 内在价值(买方) | 卖方 BTC 盈亏 = 0.025 − 内在/ $S_T$ |
|---|---|---|
| 60,000 | 0 | +0.025 BTC（满收） |
| 55,000 | 0 | +0.025 BTC |
| 50,000 | 5,000 | 0.025 − 0.1000 = −0.075 BTC |
| 45,000 | 10,000 | 0.025 − 0.2222 = −0.1972 BTC |

- 盈亏平衡（USD 直觉）≈ 55,000 − 1,500 = 53,500；跌破后亏损扩大，到标的→0 时达上限。
- 对照：买一张 $K=50{,}000$ Put 限险 → 牛市看跌价差，最大亏损被锁。`推导`（示意）
