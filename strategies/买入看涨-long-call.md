# 买入看涨（Long Call）

## 1. 一句话定义 + 市场观点
- **定义**：支付权利金，买入"以行权价 $K$ 买入标的"的权利。
- **观点**：方向**看涨**（尤其预期较大上行）+ 波动率**看升或至少不崩**。亏损封顶，适合有限风险博上涨。

## 2. 构建方式
- 买入 1 张看涨：选定 $K$ 与到期。
- **行权价选择**：越虚值（$K$ 越高）越便宜、杠杆越大、但到期归零概率越高；ATM Delta 更高、更"像标的"。
- **到期选择**：留足时间让观点兑现；越短 Theta 衰减越快（[03-Theta](../docs/02-希腊字母/03-Theta.md)）。
- **加密**：Deribit BTC/ETH 为欧式、**币本位结算**；权利金以币计（[09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)）。

## 3. 盈亏结构（USD 口径直觉）
- **最大亏损**：权利金 $p$（封顶）。
- **最大盈利**：大（标的上行）；**注意币本位下以 BTC 计封顶约 1 BTC**（[09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)）。
- **盈亏平衡**：USD 约 $K+p$；**币本位精确平衡**见 [09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)（$S_T=K/(1-p_{BTC})$）。
- **形状**：下方平坦（亏 $p$），过 $K$ 后向上倾斜。

## 4. 希腊字母特征
| 希腊字母 | 符号 | 含义 |
|---|---|---|
| Delta | + | 看涨方向敞口（0→1） |
| Gamma | + | 多头凸性，标的大动有利 |
| Theta | − | 每天付时间租 |
| Vega | + | IV 升值钱，IV 崩亏钱 |

## 5. 适用 / 不适用场景
- **适用**：明确看涨、预期有催化剂/大波动；想要**有限风险**的上行敞口；当前 IV 不算高。
- **不适用**：横盘（Theta 慢慢吃光）；IV 已在高位（事件后 [vol crush](../docs/02-希腊字母/04-Vega.md) 反噬）；只想小幅波动。

## 6. 主要风险与常见亏损方式
- **时间衰减**：看对方向但涨太慢 → Theta 把权利金耗光（最常见亏法）。
- **vol crush**：方向对但事件后 IV 暴跌 → 仍亏（[04-Vega](../docs/02-希腊字母/04-Vega.md)）。
- **全损**：到期虚值 → 损失全部权利金 $p$。
- **币本位**：上行盈利以 BTC 计被压扁、封顶约 1 BTC（[09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)）。

## 7. 调整与离场
- **止盈**：达到目标或 Delta 已很高（接近 1，凸性耗尽）时了结。
- **Roll up/out**：标的涨后上移行权价锁利、或展期换时间。
- **止损**：逻辑被证伪（催化剂落空）即离场，别死扛 Theta。

## 8. 算例（Deribit BTC）
参数：$S_0=60{,}000$，$K=65{,}000$，权利金 $p=0.03$ BTC（当时 ≈ \$1{,}800）。

| 到期 $S_T$ | USD 内在价值 | BTC payoff = 内在/$S_T$ | BTC 盈亏 = payoff − 0.03 |
|---|---|---|---|
| 60,000 | 0 | 0 | −0.03 BTC（全损） |
| 65,000 | 0 | 0 | −0.03 BTC |
| 75,000 | 10,000 | 0.1333 | +0.1033 BTC |
| 90,000 | 25,000 | 0.2778 | +0.2478 BTC |

- **币本位盈亏平衡**：由 payoff = $p$ 即 $K/S_T = 1-0.03 = 0.97$，解得 $S_T = 65{,}000/0.97 \approx 67{,}010$。
- USD 直觉平衡 ≈ 65,000 + 1,800 = 66,800；币本位略高（反向合约非线性，[09/01](../docs/09-加密期权专题/01-币本位与反向合约.md)）。`推导`（示意）
