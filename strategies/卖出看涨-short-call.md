# 卖出看涨（Short Call）

> ⚠️ **裸卖看涨（naked short call）是单腿里风险最大的策略**：上行亏损理论无限。加密 7×24 + 清算级联下尤其危险，**实务强烈建议改用备兑或价差限险**（见 §6、§7）。

## 1. 一句话定义 + 市场观点
- **定义**：收取权利金，承担"被买方按 $K$ 买走标的"的义务。
- **观点**：方向**看不涨/小跌** + 波动率**看降**（卖高 IV）。

## 2. 构建方式
- 卖出 1 张看涨：收权利金 $p$ 。
- **裸卖 vs 备兑**：裸卖无标的保护、风险无限；**备兑（持有标的同时卖 Call）**把上行风险转成"封顶收益"，远更稳。
- **价差化**：再买一张更高行权价 Call → 变成**牛市/熊市价差**，亏损封顶。
- **加密**：Deribit 币本位保证金；7×24 跳空 + 清算放大尾部。

## 3. 盈亏结构（USD 口径直觉）
- **最大盈利**：权利金 $p$ （标的 ≤ $K$ 时全收）。
- **最大亏损**：**大（裸卖理论无限）**。
- **盈亏平衡**：约 $K+p$ 。
- **形状**：上方平坦（赚 $p$ ），过 $K$ 后向下、无限。

## 4. 希腊字母特征
| 希腊字母 | 符号 | 含义 |
|---|---|---|
| Delta | − | 标的涨则亏 |
| Gamma | − | 空头凸性，大动受伤 |
| Theta | + | 每天收时间租 |
| Vega | − | IV 升则亏（怕波动放大） |

## 5. 适用 / 不适用场景
- **适用**：中性偏空、IV 处于高位想收租；**最好以备兑或价差形式**。
- **不适用**：看涨或可能暴涨；低 IV（收的租薄）；无法承受/无法及时管理尾部。

## 6. 主要风险与常见亏损方式
- **上行无限亏损**：标的暴涨 → 一次吃光多次权利金（裸卖最大风险）。
- **清算/逼空**：加密杠杆头寸保证金不足被强平，常在最坏时点。
- **Gamma/Vega 反噬**：临到期平值、IV 跳升时损失加速。

## 7. 调整与离场
- **优先限险**：买更高 Call 转**垂直价差**；或持标的转**备兑**。
- **Roll up/out**：上移行权价、展期降低被行权概率（注意可能锁亏）。
- **及时止损/买回**：突破关键位即买回平仓，别赌回落。

## 8. 算例（Deribit BTC，裸卖示意）
参数： $S_0=60{,}000$ ， $K=70{,}000$ ，权利金 $p=0.02$ BTC（≈ \$1{,}200）。

| 到期 $S_T$ | USD 内在价值(买方) | 卖方 BTC 盈亏 = 0.02 − 内在/ $S_T$ |
|---|---|---|
| 60,000 | 0 | +0.02 BTC（满收） |
| 70,000 | 0 | +0.02 BTC |
| 85,000 | 15,000 | 0.02 − 0.1765 = −0.1565 BTC |
| 100,000 | 30,000 | 0.02 − 0.30 = −0.28 BTC |

- 盈亏平衡（USD 直觉）≈ 70,000 + 1,200 = 71,200；上破后**亏损随标的上行扩大、无封顶**。
- 对照：若买一张 $K=80{,}000$ Call 限险 → 变价差，最大亏损被锁定（见垂直价差篇）。`推导`（示意）
