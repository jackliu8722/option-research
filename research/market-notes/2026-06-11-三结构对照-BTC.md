# 2026-06-11 三结构对照（BTC）

> 承接 [牛市看跌价差算例](./2026-06-11-牛市看跌价差算例-BTC.md)：**同样的市场快照、到期、IV 假设**下，把三种结构并排算清，看"不同结构怎么表达不同观点、尾部如何不同"。**IV 为假设，研究算例、不构成建议。**

## 0. 公共参数
- $S_0 = 61{,}672$，$\tau = 28/365 \approx 0.0767$，$r\approx 0$，$q=0$。
- Put 侧 IV（put skew）：\$58K put 62%、\$53K put 68%。
- Call 侧 IV（call 偏低）：\$66K call 54%、\$71K call 52%。
- 逐腿 BSM 价（USD → BTC，$P/S_0$）：

| 腿 | BSM 价(USD) | BTC |
|---|---|---|
| \$58K Put (62%) | ≈ 2,516 | 0.0408 |
| \$53K Put (68%) | ≈ 1,283 | 0.0208 |
| \$66K Call (54%) | ≈ 2,012 | 0.0326 |
| \$71K Call (52%) | ≈ 831 | 0.0135 |

> Call 腿示例：\$66K，$d_1 = \dfrac{\ln(61{,}672/66{,}000) + \tfrac{1}{2}(0.54)^2\tau}{0.54\sqrt{\tau}} \approx -0.379$，$C = S\,N(d_1) - K\,N(d_2) \approx \$2{,}012$。

---

## 1. 结构 A：牛市看跌价差（已算）
- 卖 \$58K Put + 买 \$53K Put。净贷方 ≈ **0.0200 BTC（\$1,233）**。
- 最大盈利 \$1,233 / 最大亏损 \$3,767 / 平衡 \$56,767。**两端封顶**。详见 [专篇](./2026-06-11-牛市看跌价差算例-BTC.md)。

## 2. 结构 B：限险版看涨风险逆转
- **卖 \$58K Put + 买 \$53K Put（put 价差，收 0.0200）+ 买 \$66K Call（付 0.0326）**。
- 净额 = 0.0200 − 0.0326 = **−0.0126 BTC 借方（≈ \$779）**。
- 到期盈亏（USD 直觉）：

| 到期 $S_T$ | 盈亏 |
|---|---|
| ≤ 53,000 | **−\$5,779（最大亏损，封顶）** |
| 61,672（不动） | −\$779（亏净借方） |
| 66,779（上方平衡） | 0 |
| 70,000 | +\$3,221 |
| 80,000 | +\$13,221（**上行不封顶**） |

- **要点**：用 put 价差的贷方补贴买 call → **下方封顶、上行保留凸性**——这是"逼空"行情想要的形态（对比 A 上行封顶）。

## 3. 结构 C：铁鹰（中性）
- 在 A 基础上再**卖 \$66K Call + 买 \$71K Call（call 价差，收 0.0191）**。
- 总净贷方 = 0.0200 + 0.0191 = **0.0391 BTC（≈ \$2,411）**。两侧宽度各 \$5,000。
- 最大盈利 \$2,411（**58,000 ≤ $S_T$ ≤ 66,000**）/ 最大亏损 ≈ \$2,589（击穿任一侧）/ 平衡 ≈ 55,589 与 68,411。**两侧封顶**。

---

## 4. 三方对照（核心）

| 维度 | A 牛市看跌价差 | B 限险看涨风险逆转 | C 铁鹰 |
|---|---|---|---|
| 观点 | 不大跌（中性偏多） | **看涨/赌逼空** | **区间震荡（中性）** |
| 净权利金 | +0.0200 BTC（贷） | −0.0126 BTC（借） | +0.0391 BTC（贷） |
| 最大盈利 | \$1,233 | **不封顶**（上行） | \$2,411 |
| 最大亏损 | \$3,767 | \$5,779 | **\$2,589**（最小） |
| 下方平衡 | 56,767 | ~53,000 区（见表） | 55,589 |
| 上方平衡 | — | 66,779 | 68,411 |
| 净 Delta | +0.14（偏多） | **+0.50（强多）** | ≈ −0.03（中性） |
| 净 Vega/1% | −\$16 | **+\$47（多 vol）** | −\$34（**最空 vol**） |
| Theta | 正（收租） | 略负（付 call） | 正（收双侧租） |
| 上行 | 封顶 | **凸性/不封顶** | 封顶 |
| 下行 | 封顶 | 封顶（较大） | 封顶（最小） |
| 适合 | 收 put skew、温和看多 | 赌逼空且要限险 | 高 IV、押区间、收 VRP |

---

## 5. 解读（映射到当前"两面尾部 + put skew"）

- **A（价差）**：吃 put skew、风险收益都封顶；但**踏空逼空**（上行封顶）。适合"觉得不会大跌、也不信会暴涨"。
- **B（风险逆转）**：用被高估的 put 补贴 call → **专门接逼空的凸性**，下方有底；代价是**净空 vol→多 vol**，若 IV 回落 + 横盘会双重小亏（付 call + 时间）。适合"信逼空、要参与上行"。
- **C（铁鹰）**：**最空 vol、最小最大亏损、中性**；赌区间 + IV 回落收 VRP；但**两侧都怕突破**（向下 put 墙、向上逼空都可能击穿）——在"两面绷紧"环境里，区间要选够宽、给跳空余地。

> 一句话：**同一环境，三种结构表达三种观点**——A 收租温和看多、B 赌逼空凸性、C 押区间。选哪个取决于你对"方向 + 波动率"的判断（[06/05 选择框架](../../docs/06-组合策略/05-组合策略选择框架.md)），并都要过[压力测试](../../docs/07-风险管理/03-尾部风险与压力测试.md)与[仓位预算](../../docs/07-风险管理/01-仓位管理与风险预算.md)。**不构成建议。**

## 6. caveats
- IV 全为假设；实时 IV/skew 改变全部数值与胜率（以 Deribit 为准）。
- 币本位非线性（[09/01](../../docs/09-加密期权专题/01-币本位与反向合约.md)）；多腿手续费/滑点未计入（[08/04 回测](../../docs/08-进阶与量化/04-回测方法论.md)）。
- 净 Delta/Vega 为开仓时近似，会随价格/IV/时间漂移（[07/02 动态对冲](../../docs/07-风险管理/02-组合希腊字母管理与动态对冲.md)）。
